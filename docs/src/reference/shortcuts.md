# Keyboard shortcuts

`Ctrl` on Windows/Linux, `⌘` on macOS.

| Shortcut | Action |
|---|---|
| `Ctrl/⌘ + Enter` | Send the current request (also `Enter` in the URL bar) |
| `Ctrl/⌘ + S` | Save the current request |
| `Ctrl/⌘ + T` | New tab |
| `Ctrl/⌘ + W` | Close tab (asks first when it has unsaved changes) |
| `Ctrl/⌘ + I` | Import a cURL command |
| `Esc` | Close a dialog |
| Right-click | Context menu on collections, folders, requests and environments |
| Right-click a tab | New, duplicate, close, force close, close others / to the right / all |
| Middle-click a tab | Close tab |
| Double-click | Edit an environment |
