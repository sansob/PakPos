# Roadmap

Ideas, roughly by priority. Open an issue before starting something big.

**Next**
- OAuth 2.0 (client credentials, authorization code + PKCE) and Digest auth
- Cookie jar viewer/editor
- Response search, JSON tree view, image/HTML preview
- Drag & drop to reorder requests and folders
- Per-collection settings (base timeout, TLS)

**Later**
- GraphQL request type with schema introspection
- WebSocket and Server-Sent Events
- MCP *client* request type (test MCP servers, like a REST request)
- OpenAPI 3 import / export
- Data-driven runs (CSV / JSON iterations)
- Code-signed and notarised builds; Homebrew, winget, Flatpak, AUR packages
- Translations of the UI (Bahasa Indonesia first)

**Probably not**
- Cloud accounts and sync: use git with a shared workspace folder instead.
- Full JavaScript scripting: declarative tests stay the default; a sandboxed
  scripting option may be considered later.
